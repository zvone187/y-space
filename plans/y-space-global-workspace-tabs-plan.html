Implementation Plan

Global workspace tabs for Y Space

Promote the right pane from a tool switcher into a tabbed workspace where tools and documents coexist, while keeping the proven embedded Browser page model and agent bridge intact.

StatusApproved by user direction
Branchy-space-browser-integrations
Date2026-08-27

Fast Answer

Current state

Files, Browser pages, and panel tools use three unrelated tab/state systems. File clicks leave the panel for an overlay; XLS/XLSX are generic binary files.

Recommended path

Add one outer workspace strip for Files, Git, Usage, Notes, Browser, Terminal, plans/subagents, and dynamic document tabs. Keep Browser pages nested and single-mounted.

Main risk

Reparenting Browser webviews or remounting Notes/Usage would lose state. The design therefore wraps existing owners instead of replacing them.

Resolved Product Decisions

One outer strip

Every right-pane tool opens as a labeled, selectable workspace tab. Opening the same singleton tool focuses it instead of duplicating it.

Files are documents

Source, Markdown, PDF, CSV/TSV, XLS, and XLSX files open beside tools as document tabs. Single-click preview replacement and pin/edit semantics remain.

Browser stays safe

Browser is one outer tool tab with its existing page strip, manager, persistence, OAuth behavior, and agent MCP. No external browser is introduced.

Implementation Shape

Reuse

  • panelStore tool contexts/open flags
  • fileEditorStore buffers and preview/pin logic
  • BrowserPanelManager and Browser MCP
  • Existing Notes, Usage, Git, Terminal, plan, and subagent components

Change

  • Add a discriminated workspace-tab registry and deterministic selection/close/reorder helpers
  • Render a keyboard-accessible global strip in UnifiedRightPanel
  • Route ordinary file opens through a single workspace action
  • Add a bounded, allowlisted document-preview IPC for PDF/XLS/XLSX bytes and render documents inline instead of opening the modal by default

New Preview Capability

PDF

Request bytes through a new size-bounded, extension-allowlisted preview IPC, create a renderer-local Blob URL, and display it inside the document tab. Revoke the URL on tab change/unmount.

Spreadsheet

Use SheetJS CE 0.20.3 from its authoritative distribution to parse XLS/XLSX locally, with sheet selection and a bounded read-only grid. CSV/TSV share the grid.

Safety limits

No network viewer, no macro execution, no formulas evaluated, no write-back. Malformed, encrypted, remote-unavailable, and oversized files show finite errors.

TDD Contract

Failing tests to add first
  1. Workspace IDs cannot collide; singleton tools focus idempotently; document paths coexist.
  2. Close picks an adjacent tab, closing dirty documents can be cancelled, and reorder preserves selection.
  3. The global strip has exactly one selected tab, roving keyboard focus, Home/End/arrow support, close focus restoration, and overflow access.
  4. Tree, chat/file path, Git, command, PDF, and spreadsheet opens route through the workspace action without a modal.
  5. Browser → file → Git → Browser preserves the same Browser host/webview nodes and does not duplicate pages.
  6. PDF opening is single-instance and Blob URLs are revoked.
  7. XLS/XLSX/CSV/TSV render sheet names and cells; malformed, encrypted, and oversized files fail safely.
  8. Inactive document panes cannot intercept Cmd/Ctrl+W, Save, Find, or Browser reload shortcuts.
Manual user stories
  • Open Files, Git, Notes, Usage, and Browser from the current top-right controls; each appears as its own outer tab and keeps its state while switching.
  • Open two source files, one PDF, one XLS, and one XLSX; each appears as a separate document tab and no external app launches.
  • Reorder and close mixed tool/document tabs, then verify the correct neighbor receives focus and dirty work is protected.
  • Keep several Browser page tabs open, switch through document/tool tabs, return to Browser, and verify all pages and agent control still work.

Constraints And Boundaries

Scope boundary
The outer workspace is scoped to the current project/worktree in this implementation. Existing Browser page persistence remains cross-launch. File contents and dirty buffers remain session-only unless an existing editor restore contract already applies; no content is silently persisted.
Dependency decision
Add SheetJS Community Edition 0.20.3 from https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz, following the project's pnpm lockfile. The full build is required because the mini build omits XLS. No PDF dependency is needed.
