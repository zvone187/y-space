Design guardrails

Apple hierarchy

Glass is the functional navigation/control layer, used sparingly so content remains dominant. Text-heavy surfaces use a regular, contrast-safe material.

Electron reality

Electron exposes AppKit vibrancy, not Tahoe's NSGlassEffectView. The safe edge effect is an honest rim approximation, not claimed pixel refraction.

Performance boundary

One filtered host per stable region. No per-tab, row, guest, webview, Browser-host, or content-plane filters.
