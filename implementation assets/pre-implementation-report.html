Design opportunity and invariant

What feels flat today

  • The light sidebar is technically translucent but its 98% tint reads opaque.
  • The global tab rail and browser toolbar are flush, square separators.
  • The composer already blurs but its material reads like a plain white card.
  • Softening every pane would create visual noise and costly compositor layers.

New visual invariant

  • One glass capsule contains every global workspace tab.
  • Real blur is limited to stable shell chrome, never a tab or webview.
  • Browser/thread toolbars imitate glass with paint-only highlights and shadows.
  • Orange remains the only strong action, focus, and selected accent.

End-to-end verification plan

Resting light shell

Launch the unsigned package with a representative task and embedded browser visible. Capture sidebar, thread header, one global tab strip, browser controls, and composer.

Focus and menus

Focus the composer, open a browser or overflow menu, and verify the orange focus state, glass depth, text clarity, dismissal, and keyboard semantics.

Global tabs

Switch Browser, Files, Git, and a document with mouse and keyboard; reorder and close a disposable peer. One tablist and one selected orange indicator must remain.

Embedded browser

Type into the rounded address field, navigate, reload, open the browser menu, and resize the pane. Web content must stay crisp and every control must remain clickable.

Accessibility

Verify reduced-transparency opaque fallbacks and a brief dark-mode regression, then return to the requested light appearance. Check all boundaries and muted text.

Layer and memory guard

Exercise more than six browser metadata tabs in an isolated profile. Confirm only the single strip blurs, resident guests stay capped at six, and cleanup has no new leak slope.

Risks and controls

Too much glass
Glass is restricted to the native sidebar, global strip, composer, and small menus. Browser/thread toolbars use faux material; panes and content remain opaque.
Contrast over unknown wallpaper
Platform-specific frosting floors keep a theme scrim behind text. Glass-local muted ink clears 4.5:1 in pessimistic light blends, and reduced transparency paints solid surfaces.
Memory and browser residency
Closed work bodies are unmounted. Existing browser LRU limits remain unchanged: six ordinary live webviews, four sensitive live webviews, and thirty metadata entries. No filter, rounded clipping, opacity, or persistent will-change touches browser guests.
Interaction geometry
Structural pane edges and resize handles stay square. New radius is applied inside those boundaries, with global-tab roving focus, drag/reorder, close targeting, browser actions, and macOS drag regions covered by regression tests and hands-on clicks.

Decision
