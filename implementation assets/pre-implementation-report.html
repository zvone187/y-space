Safety Gates

OAuth is sensitive

Private Connect URLs, browser cookies, tokens, and authorization pages never become renderer screenshots, persistence, or agent Browser targets.

Gmail remains read-only

The acceptance call may list bounded metadata or count unread items. Sending, deleting, moving, labeling, or marking mail is outside this test authorization.

Disconnect is exact

Authorization derives from the scoped local account store, not a renderer-supplied syntactically valid id. Revoke locally before remote mutation.
